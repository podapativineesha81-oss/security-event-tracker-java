# Security Event Tracker (Java)

A simple console-based **Security Event Tracker** developed using Core Java and Object-Oriented Programming (OOP).

The application allows users to record and manage basic security event information through a menu-driven interface.

## Features

- Add security events
- View all security events
- Search event by ID
- Update event information
- Delete security events
- Store event names
- Categorize security events
- Store event sources
- Track severity levels
- Track event status
- Menu-driven interface
- ArrayList-based storage

## Technologies Used

- Java
- Object-Oriented Programming
- ArrayList
- Scanner
